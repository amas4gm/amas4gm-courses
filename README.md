# AMAS4GM Bambu Studio course

Tutorial 01: workspace orientation and 3D navigation. Clearly labeled simulation; no printer connection, slicing, or printing.

The interface is reconstructed from the installed Bambu Studio Prepare workspace. The included Benchy.stl is the exact supplied course model, with its original sideways orientation retained. Only the current learning concept is interactive. Camera navigation uses left drag on empty space, right/middle drag to pan, and wheel zoom. Keyboard and touch practice buttons are supplied outside the slicer UI.

## Run
Serve this directory with any static HTTP server. Open index.html. Local file URLs cannot fetch the STL. No build step or external scripts required.

## Scope
13 guided steps plus free navigation practice. Other course lessons and assessment policies are not implemented here. Completion is browser-local practice progress, not a Moodle grade or shop printing authorization. Model editing and print controls remain disabled.

## Hosting
Publish main from repository root in GitHub Pages. Embed its HTTPS URL in OpenLearn Create where iframes are permitted. A desktop or laptop and mouse are recommended for the native-size interface.
